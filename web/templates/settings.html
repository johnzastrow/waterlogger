Database Migration (SQLite ↔ MariaDB)

To migrate data between SQLite and MariaDB, use the command line tools:

Migrate from SQLite to MariaDB:

./waterlogger -config config.yaml -migrate-to-mariadb

Migrate from MariaDB to SQLite:

./waterlogger -config config.yaml -migrate-to-sqlite

⚠️ Important: Database migration requires stopping the application. Backup your data first!

See MIGRATIONS.md for complete documentation.
